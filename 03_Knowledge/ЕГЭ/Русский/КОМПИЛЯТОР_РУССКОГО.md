# ⚡ КОМПИЛЯТОР РУССКОГО ЯЗЫКА (ЕГЭ 100 БАЛЛОВ)

> *«В правилах языка нет хаоса, если переписать их как детерминированный конечный автомат. Каждое правило — это бинарная ветка if / else. Ошибка — это баг парсера, который устраняется изолированным патчем».*

  (ЧГ / ПГ / НПГ)          (Управление / Обороты)   (ТО / НО / ТАК)

## 2. Модуль 01: Корни слов (Задание №9)

### Дерево решений (AST):
```text
IF корень в списке Чередующихся (ЧГ):
    ├── От ударения: ГАР/ГОР, КЛАН/КЛОН, ТВАР/ТВОР (без уд. О); ЗАР/ЗОР (без уд. А); ПЛОВ/ПЛАВ
    ├── От суффикса -А-: БЕР/БИРА, ДЕР/ДИРА, МЕР/МИРА, ПЕР/ПИРА, ТЕР/ТИРА, ЖЕГ/ЖИГА, СТЕЛ/СТИЛА, БЛЕСТ/БЛИСТА
    ├── От согласной: РАСТ/РАЩ/РОС, СКАК/СКОЧ, ЛАГ/ЛОЖ
    └── От значения: МАК (погружать) / МОК (пропускать жидкость); РАВН (одинаковый) / РОВН (гладкий)
    -> [STOP: Нельзя проверять однокоренным словом!]
ELSE:
    IF можно подобрать проверочное слово с ударением на гласную:
        └── [ПГ: Проверяемая гласная] (пример: примИрять врагов -> мИр)
    ELSE:
        └── [НПГ: Непроверяемая словарная гласная] (пример: винегрет, палисадник)
```

> **Критический баг (False Positive)**: Омонимичные корни!
> - `мИрить` — это НЕ чередование `мер/мир` (нет значения смерти/замирания). Это ПГ (`мир`).
> - `гОревать` — это НЕ чередование `гар/гор` (нет значения горения). Это ПГ (`гОре`).

## 3. Модуль 02: Синтаксические нормы (Задание №8)

### Таблица бинарных ловушек компилятора:

| Ошибка парсера | Симптом в коде предложения | Алгоритм фикса (IF / THEN) |
| :--- | :--- | :--- |
| **Деепричастный оборот** | Действие оборота не привязано к подлежащему | **IF** подлежащее предложения не совершает действие деепричастия -> **BUG**. Безличные предложения (кроме инфинитива) с деепричастием -> **FATAL BUG**. |
| **Причастный оборот** | Разрыв оборота или неверное согласование | **IF** определяемое слово стоит ВНУТРИ причастного оборота -> **BUG**. Проверить окончание вопроса: *какому? -> играющЕМУ*. |
| **Однородные члены** | Разрушение параллелизма | **IF** двойной союз сломан (*не только..., но И*, а не *а также*) -> **BUG**. Глаголы требуют разных падежей от одного дополнения (*любить и восхищаться [кем? чем?]*) -> **BUG**. |
| **Несогласованное приложение** | Название в кавычках (*роман «Война и мир»*) | **IF** есть родовое слово (*роман, газета, фильм*) -> название ВСЕГДА в Им. падеже. **IF** родового слова нет -> склоняется само название. |
| **Связь подлежащего и сказуемого** | Конструкции *«Все, кто...» / «Те, кто...»* | Формула: `[Те (мн.ч.)], [кто (ед.ч.) пришел (ед.ч.)], [остались (мн.ч.)]`. Если `Те остался` -> **BUG**. |

## 4. Модуль 03: Пунктуация на стыке союзов (Задание №20)

### Правило «ТО / НО / ТАК»:
```text
Стык двух союзов: [..., и (если / когда / хотя)...]
                     │
         Встречается ли дальше по коду "ТО", "НО" или "ТАК"?
                     ├── ДА  -> Запятая на стыке союзов НЕ СТАВИТСЯ! (жадный оператор забирает запятую)
                     └── НЕТ -> Запятая на стыке союзов СТАВИТСЯ!
```
