"Под влиянием непростых обстоятельств формировалось мировоззрение выдающегося получившего Нобелевскую премию писателя." - как оформить в повторении

Под влиянием непростых обстоятельств формировалось мировоззрение выдающегося**,** получившего Нобелевскую премию писателя. **— одна запятая (определения «выдающегося», «получившего Нобелевскую премию» относятся к одному слову («писателя») и являются однородными: если** **перед** **распространённым определением («получившего Нобелевскую премию») стоит одиночное («выдающегося»), то они разделяются запятой))**
_В июльские_ _вечера_ **_и_** _ночи_ уже не кричат перепела **и** коростели **и** не поют в лесных балках соловьи. **— нет запятых (в предложении две грамматические основы: «****перепела, коростели не кричат****», «****соловьи** **н****е поют»; они связаны сочинительным союзом «И» (сложносочинённое предложение); есть общий второстепенный член –** **_«в июльские вечера и ночи»_** **(обстоятельство времени, которое относится к обеим частям ССП) => запятая** **не ставится****; перед нами две группы однородных членов: обстоятельства «(в) вечера», «(в) ночи» соединены с помощью одиночного союза** **«И» => запятая не ставится; подлежащие** **«перепела», «коростели» соединены с помощью одиночного союза** **«И» => запятая не ставится****)**
Быстроходность **и** неприхотливость**,** простое парусное снаряжение **и** сравнительно небольшой экипаж обеспечили каравелле широкое распространение в странах южной Европы. **— одна запятая (перед нами следующие однородные члены предложения: «быстроходность, неприхотливость», «снаряжение, экипаж»; однородные в каждой из пар подлежащих соединены с помощью союзов «И» => при такой схеме запятая ставится между парами однородных (схема: О и О, О и О);** **в** **предложении также есть неоднородные определения «простое» и «парусное», они с разных сторон характеризуют главное слово «снаряжение», а также относятся к разным разрядам («простое» – качественное прилагательное, а «парусное» – относительное), поэтому не требуют постановки запятой)**
Прежнее деление Сахалина на северный, средний и южный неудобно в практическом отношении, и теперь его делят только на северный и южный. — две запятые (перед нами две грамматические основы: «деление неудобно», «делят»; они соединены с помощью сочинительного союза «И» (сложносочинённое предложение), общего второстепенного члена предложения нет => ставится запятая; в предложении две группы однородных членов: «северный», «средний» связаны только интонацией (союзов нет) => разделяются запятой, «средний», «южный» соединены с помощью одиночного союза «И» => запятая не ставится (схема: О, О и О); «северный», «южный» соединены с помощью одиночного союза «И» => запятая не ставится)
Изредка перешёптывались листья**,** **да** отрывисто жужжали запоздалые пчёлы**,** **да** где-то однообразно **и** неутомимо ворковала горлинка. **— две запятые (в предложении три грамматические основы: «****листья перешёптывались****»,** **«пчёлы жужжали», «горлинка ворковала»; они связаны** **повторяющимся** **сочинительным союзом «ДА» (у первой основы он опущен) => запятая ставится после каждой из частей предложения (кроме последней) – работает точно такое же правило, как и с повторяющимся союзом при однородных членах предложения; однородные обстоятельства «однообразно», «неутомимо» соединены одиночным союзом «И» => запятая не ставится)**
Я выхожу на крышу**,** снимаю шляпу**,** **и** в голову мою дует с запада сильный **и** прохладный ветер. **— две запятые (в предложении две грамматические основы: «я выхожу, снимаю», «ветер дует»; они соединены с помощью сочинительного союза «И» (сложносочинённое предложение), общего второстепенного члена предложения нет => ставится запятая; однородные сказуемые «выхожу», «снимаю» связаны только интонацией (союзов нет)** **=> разделяются запятой; однородные определения «сильный», «прохладный»** **соединены с помощью одиночного союза** **«И» => запятая не ставится****)**
