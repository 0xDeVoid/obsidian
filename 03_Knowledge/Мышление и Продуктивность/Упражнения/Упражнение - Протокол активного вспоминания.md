# 🛠️ УПРАЖНЕНИЕ: ПРОТОКОЛ АКТИВНОГО ВСПОМИНАНИЯ И СПАРРИНГА С ЗАДАЧЕЙ

> *«В схватке побеждает тот, кто атакует до того, как противник успеет завершить движение. Просмотр чужого решения без собственного боя — это иллюзия силы».*

---

## 01 // ЦЕЛЬ ПРАКТИКИ

Перевести процесс усвоения сложной информации из пассивного поглощения контента в режим жесткого активного спарринга. Ликвидировать иллюзию понимания, натренировать емкость оперативной памяти и закрепить навык самостоятельного рассуждения в условиях неопределенности.

---

## 02 // ТРИГГЕРЫ ДЛЯ АКТИВАЦИИ

- Просмотр вебинара или видеолекции по сложной теме (профильная математика, русский язык, программирование).
- Ощущение тупика при решении задачи 2-й части.
- Необходимость надежно запомнить блок теории, доказательство теоремы или синтаксическую структуру.
- Вынужденное «мертвое время» (дорога в транспорте, очередь, ожидание).

---

## 03 // ПОШАГОВЫЙ АЛГОРИТМ

```text
[ Лектор вывел условие задачи ]
               │
               ▼
   [ ⏸️ ЖЕСТКАЯ ПАУЗА ВЕБИНАРА ]
               │
               ▼
[ 3–5 МИНУТ САМОСТОЯТЕЛЬНОГО БОЯ ]
(Черновик, чертеж, уравнение, анализ)
               │
     ┌─────────┴─────────┐
     ▼                   ▼
[ Решил сам ]     [ Полный тупик ]
     │                   │
     │                   ▼
     │            [ Снять с паузы на 15-20 сек ]
     │            (Смотреть ТОЛЬКО первый хинт лектора)
     │                   │
     │                   ▼
     │            [ ⏸️ СНОВА ПАУЗА ]
     │            (Дорешать самому по подсказке)
     │                   │
     └─────────┬─────────┘
               ▼
[ Сверить ответ и оформить в базу знаний ]
```

### Протокол А: Опережающий удар (Во время лекций)
1. **Пауза по условию**: Как только лектор показал формулировку задачи — немедленно нажми пробел (пауза).
2. **Спарринг 3–5 минут**: Засеки таймер. Выпиши дано, сделай чертеж, протестируй граничные случаи, попробуй метод «в лоб».
3. **Дозированный хинт**: Если наступил тупик — сними с паузы ровно до первой наводящей мысли лектора (15–20 секунд) и снова жми пробел. Добивай решение самостоятельно.
4. **Сверка архитектуры**: Сравни свое решение с решением автора. Если твой путь длиннее — зафиксируй оптимальный инвариант.

### Протокол Б: «Стендап Фейнмана» (Для сложных тем)
1. Выбери тему, вызывающую ступор (например, метод вспомогательного угла или корни с чередованием).
2. Включи диктофон или открой чистый лист в Obsidian.
3. Объясни тему вслух языком уличного стендапа:
   - Без сложной терминологии.
   - С жесткими жизненными метафорами.
   - С юмором или легким сарказмом.
4. Отметь места, где запнулся или вернулся к заученным формулировкам из учебника. Это и есть твои **когнитивные дыры**. Открой теорию и точечно закрой именно их.

### Протокол В: Слепая визуализация (В «мертвое время»)
1. Закрой глаза в транспорте или на прогулке.
2. Мысленно воспроизведи чертеж: треугольник $ABC$, высоты $AH_1$ и $CH_2$, точка пересечения $H$, окружность через точки $B, H_1, H, H_2$.
3. Удерживай чертеж в голове не менее 2 минут, проговаривая углы и подобия. Это тренирует объем RAM префронтальной коры.

## 04 // ШАБЛОН ДЛЯ ЗАПОЛНЕНИЯ В OBSIDIAN

### 1. Журнал опережающего удара
```text
Дата сессии: {{date}}
Источник: [Название вебинара / номер ДЗ]

| № Задачи | Время соло (мин) | Результат (Сам / Хинт / Тупик) | Где споткнулся (Точка бага) |
| :---: | :---: | :---: | :--- |
| Задача 1 | 4:30 | Решил сам | Забыл проверить ОДЗ в логарифме |
| Задача 2 | 5:00 | Хинт (15 сек) | Не увидел подобие прямоугольных треугольников |
| Задача 3 | 3:15 | Решил сам | Чистовик с первой попытки |
```

### 2. Карточка Фейнмана
```markdown
### 🎙️ Тема: [Название сложной темы]

- **Суть в одном предложении (для 10-летнего)**:
  > 

- **Аналогия из реальной жизни / Метафора**:
  > 

- **Дерево решения (IF / THEN алгоритм)**:
  ```text
  IF ...
  ├── THEN ...
  └── ELSE ...
  ```

- **Дыры в моем понимании, которые вскрыл пересказ**:
  - [ ] 1. 
  - [ ] 2. 
```

### 3. Трекер интервальных повторений
- [ ] **Сессия 0 (День 0)**: Первичное активное решение.
- [ ] **Сессия 1 (+24 часа)**: Воспроизведение решения на чистом листе без подглядывания.
- [ ] **Сессия 2 (+3 дня)**: Решение задачи-клона с другими числами.
- [ ] **Сессия 3 (+7 дней)**: Включение в смешанный пробный вариант.
- [ ] **Сессия 4 (+21 день)**: Контрольная проверка остаточного следа.

## 05 // ТИПИЧНЫЕ ОШИБКИ И АНТИПАТТЕРНЫ

1. **Синдром кинотеатра**: Смотреть 3 часа вебинара под чай и печенье, не касаясь ручки и черновика. КПД такого просмотра равен 5–7%.
2. **Паника чистого листа**: Боязнь сделать ошибку на черновике. Черновик создан для того, чтобы ошибаться и тестировать гипотезы.
3. **Игнорирование тайминга паузы**: Сидеть над одной задачей в мертвом ступоре более 10 минут во время просмотра вебинара. Если за 5 минут идей нет — бери хинт и двигайся дальше.
4. **Скучный пересказ по памяти**: Заучивание определений слово в слово вместо перевода на собственный внутренний язык.
